## 📖 Tentang Repositori

Repositori **Archive Skripsi** digunakan sebagai tempat penyimpanan dan dokumentasi berkas yang berkaitan dengan pengerjaan skripsi atau tugas akhir. Berkas dikelompokkan berdasarkan jenisnya agar lebih mudah ditemukan, dipelajari, dan ditinjau kembali.

Secara umum, repositori ini mencakup:

- **Kode sumber** yang berkaitan dengan pengembangan atau implementasi penelitian.
- **Artefak** atau berkas keluaran yang mendukung dokumentasi pekerjaan.
- **Dokumen TKT** yang disimpan terpisah dari kode sumber dan artefak.

> **Catatan:** Repositori ini berfungsi sebagai arsip proyek penelitian. Detail judul, metode, kebutuhan perangkat lunak, serta cara menjalankan implementasi perlu merujuk pada berkas yang tersedia di masing-masing folder.

## 🗂️ Struktur Repositori

```text
archive-skripsi/
├── TKT/                  # Dokumen yang berkaitan dengan TKT
├── artefak/              # Artefak dan berkas keluaran penelitian
├── source-code/          # Kode sumber proyek penelitian
└── README.md             # Dokumentasi utama repositori
```

| Direktori | Deskripsi | Akses |
| :-- | :-- | :-- |
| `TKT/` | Kumpulan berkas pendukung yang dikelompokkan sebagai TKT. | [Buka folder](./TKT) |
| `artefak/` | Artefak atau luaran terkait proses penelitian dan pengembangan. | [Buka folder](./artefak) |
| `source-code/` | Berkas kode sumber yang terkait dengan implementasi penelitian. | [Buka folder](./source-code) |

## 🚀 Cara Mengakses

### 1. Melalui GitHub

Buka folder yang ingin dilihat langsung melalui tautan pada tabel struktur repositori di atas. Pilih berkas untuk melihat isinya atau mengunduhnya apabila formatnya didukung.

### 2. Melalui Git

Pastikan [Git](https://git-scm.com/) sudah terpasang, kemudian jalankan:

```bash
git clone https://github.com/wahyusw813/archive-skripsi.git
cd archive-skripsi
```

Selanjutnya, buka direktori yang dibutuhkan:

```bash
cd source-code
```

### 3. Mengunduh Tanpa Git

Pada halaman utama repositori, pilih **Code → Download ZIP**, lalu ekstrak berkas yang telah diunduh.

## 💻 Meninjau dan Menjalankan Kode

Kode sumber disimpan pada direktori [`source-code/`](./source-code). Untuk menggunakan atau menjalankannya:

1. Buka direktori `source-code/` dan identifikasi berkas utama proyek.
2. Periksa apakah terdapat petunjuk instalasi, konfigurasi, atau daftar dependensi.
3. Siapkan lingkungan pengembangan sesuai bahasa pemrograman dan framework yang digunakan oleh kode tersebut.
4. Jalankan proyek berdasarkan petunjuk yang tersedia pada berkas terkait.

**Penting:** Perintah instalasi dan eksekusi yang spesifik tidak dicantumkan di sini karena belum diverifikasi dari isi kode sumber. Jangan mengasumsikan bahwa seluruh berkas dapat dijalankan tanpa konfigurasi tambahan.

## 🎯 Tujuan Dokumentasi

Repositori ini disusun untuk:

- Mengarsipkan berkas penelitian dalam satu tempat.
- Memisahkan kode sumber, artefak, dan dokumen pendukung.
- Mempermudah penelusuran hasil pekerjaan serta proses pengembangan.
- Menyediakan referensi bagi pengembangan, evaluasi, atau penelitian lanjutan.

## 📝 Catatan Penggunaan

Materi dalam repositori ini merupakan bagian dari dokumentasi tugas akhir. Jika menggunakan kode, dokumen, atau artefak sebagai referensi, mohon mencantumkan atribusi yang sesuai dan mematuhi ketentuan akademik yang berlaku.

**Lisensi:** Belum ada berkas lisensi yang tercantum pada direktori utama saat README ini disusun. Ketersediaan publik di GitHub tidak otomatis berarti seluruh materi bebas digunakan ulang, dimodifikasi, atau didistribusikan.
